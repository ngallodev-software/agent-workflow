# MOD-GATE-0 — decomposition gate

Independently verify that each move is behavior-preserving, dependency direction is clearer, compatibility facades are deliberate, and no new product scope was hidden in the refactor. Rerun release audit and installed/core tests. Accept or reject; do not implement new scope.

## Writable paths

Review evidence only. Do not modify production source.

## Acceptance

Accept only when behavior and artifact bytes remain compatible, dependency direction improves, and every changed public import is preserved or deliberately migrated.

## Tests

Independently rerun the focused installed journeys, invariants, prompt-pack validation, and release audit.

## Stop conditions

Reject unexplained behavior changes, mixed feature work, hidden schema changes, or a refactor too broad to review atomically.
