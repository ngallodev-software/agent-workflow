# force-accept-override

Implement one audited, explicit manual lifecycle override without weakening the
ordinary acceptance path. It is a local operator surface, not proof of
authenticated human identity; that boundary remains owned by HARD-007.

Validate with `agent-workflow pack validate`, create an isolated worktree with
`agent-workflow worktree create`, and launch through `agent-workflow launch`.
A valid tmux context yields a visible pane; otherwise launch uses a detached
named session. Native host subagents are not durable runs unless bridged by the
CLI.
