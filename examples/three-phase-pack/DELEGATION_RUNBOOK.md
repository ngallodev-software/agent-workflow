# Delegation Runbook

1. Validate the pack.
2. Create the ticket worktree.
3. Prepare an Agent Run from the ticket prompt.
4. Start it in headless mode or hand the prepared plan to a supported external runtime.
5. Observe durable status/progress.
6. Persist steering and require acknowledgement.
7. Collect completion and evaluation evidence.
8. Review and accept/reject separately.
